How to reach JDownloader

My.JDownloader account

Same login as JDownloader → Settings → My.JDownloader on the PC. The password is only used once to derive the API secrets and is not stored.

Local Click'n'Load

JDownloader listens on port 9666 on the PC. In JDownloader: Settings → Advanced Settings → search localhostonly → untick it for the Deprecated API (Click'n'Load), then restart JDownloader. The phone must be on the same network or a VPN (e.g. Tailscale) to the PC.
